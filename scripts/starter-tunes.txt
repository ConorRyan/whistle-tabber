# Starter set: tunes from O'Neill's Music of Ireland (1850), O'Neill's Project
# transcriptions (GPL-2+), fetched by scripts/build-starter-set.sh.
#
# Chosen to fit a D whistle without octave folding (written D to b'), with no
# accidentals beyond C natural, and to parse in abcjs without warnings.
# The 1850 collection has no polkas; Dan Rogers' slide is the only slide, and
# is kept although its D sharps need a half-hole.
#
# Format: <file in _1850/X/> | <R: value we set> | <title, for humans>
#         [| <Z: credit to add when the file has no Z: line>]
# Many 1850 transcriptions have no R: line, and the rest spell rhythms
# differently ("slipjig", "double jig"), so the script sets R: from column 2.
